## Notes

This repository is the Mentally Healthy Productions site, cloned from the WJ Craft 5 boilerplate. Do not import CSS, colours, fonts, or node IDs from the Royal Free prototype.

The boilerplate has one Vite pipeline: `src/` builds to `web/dist`. `index.html` and `dev.html` are the pattern library. Add one specimen section per built component. Do not add a second library.

Graphik Regular (400) and Semibold (600) are the body fonts. Titling Gothic FB Normal Medium (500) is the heading font. Extended and Wide Medium are loaded for the other Titling Gothic widths. Headings use weight 500 because the supplied file is Medium, not Bold.

DDEV project name is `mhp-website` (`https://mhp-website.ddev.site`). `origin` was removed so this clone cannot be pushed back to the boilerplate. Craft is not installed yet: copy `.env.example.dev` to `.env`, then `ddev start` and `ddev composer install` before a CMS check.

Skipped on the Design system page because they are foundations or internal pieces: colour, type styles, spacing, icons, link styles, buttons, form controls, header, footer, breadcrumbs, pagination, tags, chart, tables, and frames named `Blocks / …`. Image caption is part of Image / Body.

Pattern-library foundations now include Legend, the question controls, the error summary, the primary button, header, footer, the basic table, and pagination. They are specimens only. Craft Formie and the existing header and footer templates are unchanged.

Pattern-library foundations now also include colour, spacing, type, link styles, tags, breadcrumbs, the back link, the chart, the responsive table, hint text, the definition tooltip, search, close search, and both CTA buttons. CSS is `src/styles/matrix/specimens.css`. They are specimens only.

Action-plan specimens now include the completed-actions bar, the error message, copy URL, and the sharing panel. Still to add: the question, the group, and the backdrop.

Pictogram lists, tick lists, stats, testimonials, and the action plan hero are pattern-library only. They have no entry type, so they are not rendered from Craft. Do not add project config until these handles are agreed: `block__iconList` (pictogram and tick), `block__stats`, `block__testimonial`, and an action-plan entry type for the step hero.

Document downloads uses `block__actionLink` with `assetLink`. The link label, file format, and file size come from the asset link. Cover image, description, and length have no fields, so Craft shows the fallback icon and omits the description and length. The pattern library specimen includes both covers and the description.
